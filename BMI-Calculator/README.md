# BMI Calculator

A modern desktop BMI (Body Mass Index) Calculator built with **Python** and **Tkinter**. This application allows users to calculate their BMI based on height and weight, displays the corresponding BMI category, and provides a short health recommendation through a clean and user-friendly interface.

---

## Features

- Modern dark-themed graphical interface
- Accurate BMI calculation
- Input validation with error messages
- BMI categories:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Personalized health advice
- Reset button
- Keyboard shortcut (Press **Enter** to calculate)
- Clean and responsive layout

---

## Technologies Used

- Python 3
- Tkinter
- Object-Oriented Programming (OOP)

## Installation

1. Clone the repository

```bash
git clone <https://github.com/KhushRawat-4/OIBSIP>
```

2. Navigate to the project folder

```bash
cd BMI-Calculator
```

3. (Optional) Create a virtual environment

```bash
python -m venv .venv
```

Activate it:

**Linux/macOS**

```bash
source .venv/bin/activate
```

**Windows**

```bash
.venv\Scripts\activate
```

4. Install dependencies

```bash
pip install -r requirements.txt
```

---

## Running the Application

```bash
python main.py
```
