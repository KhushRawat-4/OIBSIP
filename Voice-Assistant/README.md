# 🎙️ Voice Assistant (OIBSIP)

A Python-based Voice Assistant developed as part of the Oasis Infobyte Internship Program. The assistant can recognize voice commands, respond using natural text-to-speech, perform web searches, open applications, and provide useful information like the current time, date, and weather.

---

## ✨ Features

- 🎤 Voice command recognition
- 🔊 Natural voice responses using Microsoft Edge TTS
- 🌐 Google search
- 📅 Current date
- 🕒 Current time
- 🌤️ Weather by city
- 🌍 Open websites
- 💻 Launch desktop applications
- 🖥️ Simple Tkinter GUI
- ⌨️ Command-line mode

---

## 🛠️ Technologies Used

- Python 3
- Tkinter
- SpeechRecognition
- Edge TTS
- Requests
- Webbrowser
- OpenWeather API

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/KhushRawat-4/OIBSIP.git
```

Go to the project folder:

```bash
cd OIBSIP/Voice-Assistant
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it:

Linux/macOS

```bash
source .venv/bin/activate
```

Windows

```cmd
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

Command-line version:

```bash
python main.py
```

GUI version:

```bash
python gui.py
```
